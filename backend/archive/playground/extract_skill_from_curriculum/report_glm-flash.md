## Introduction to Artificial Intelligence  (GICI51INA)

- **File:** `GICI51INA_AI_2024_2025.md`
- **Credits:** 2.0 · **Programme:** — · **Category:** it

### Description

This course focuses on studying the fundamentals of Artificial Intelligence (AI) that provide systems the ability to learn and improve from experience without being explicitly programmed automatically. this fundamental of understanding will focus on the development of computer programs that can access data and use it learn for themselves. In this class, the students will learn about some of the most effective machine learning techniques along with hands-on practices. In addition to the theoretical foundations of learning, the students will also acquire the practical know-how needed to quickly and powerfully apply these techniques to new problems.

### Course Learning Outcomes (6)

1. CLO1 Recall the definitions of key machine learning terms like supervised learning, unsupervised learning, deep learning, and model evaluation metrics (accuracy, precision, recall, etc.).
2. CLO2 Explain the core concepts behind machine learning algorithms (linear regression, logistic regression, decision trees).
3. CLO3 Apply appropriate data pre-processing techniques to prepare data for machine learning tasks.
4. CLO4 Analyze the strengths and weaknesses of different machine learning algorithms for a specific task.
5. CLO5 Evaluate the performance of machine learning models and diagnose potential issues like overfitting or underfitting.
6. CLO6 Design and implement a machine learning pipeline to solve a real-world problem using machine learning techniques.

### Lessons (16)

- **Week 1** — Introduction to AI & Machine Learning
    - Understanding the AI definition and sub-field of AI
    - Differentiate the differences between AI and ML.
    - Differentiate the differences type of ML
    - Understand the life cycle of ML
- **Week 2** — Data Preprocessing
    - Learn how to split data into training, testing, and optionally validation sets.
    - Learn about feature scaling and when to apply this to the dataset
    - Understand what is feature encoding and its types
- **Week 3** — Training and Evaluation
    - Differentiate the difference between parameters and hyperparameters.
    - Learn how to split data into training, testing, and optionally validation sets.
    - Master different kinds of metrics for evaluation according to any given problem.
- **Week 4** — Linear Regression
    - Differentiate Linear and Nonlinear Correlation
    - Know the basic concept of the cost function
    - Understand Gradient Descent Optimization algorithm
    - Able to find the best fit line via either least square and gradient descent
- **Week 5** — Project
    - Know techniques to find datasets
    - Define a clear problem statement and identify a suitable machine learning task (classification, regression, clustering, etc.
    - Implementation any algorithms to any datasets (students choose a dataset and algorithms)
- **Week 6** — Logistic Regression
    - Understand the limitation of linear regression for classification problem
    - Understanding different between regression and classification
    - Applying logistic regression algorithm to student Admission
    - Know the concept of the sigmoid activation function
- **Week 7** — Support Vector Machine
    - Understand the concept behind SVM
    - Able to use SVR and SVC for their respective problems
    - Able to tune hyperparameters so that the model could perform better
- **Week 8** — Decision tree
    - Describe the structure of a decision tree, including nodes, branches, and leaves.
    - Understand the concept of information gain and entropy as splitting criteria.
    - Discuss the use of decision trees in various domains (e.g., finance, healthcare, marketing).
    - Applying decision tree or linear regression algorithm to predict Breast Cancer
- **Week 9** — Random Forest-Ensemble Method
    - Define ensemble methods and explain the concept of combining multiple models to improve predictive performance.
    - Understand the key principles of bagging and boosting as ensemble techniques.
    - Describe the Random Forest algorithm as an ensemble of decision trees.
    - Applying decision tree or linear regression algorithm to predict Breast Cancer
- **Week 10** — Introduction to Deep Learning
    - Understanding what is deep learning
    - Realize the differences between ML and DL
    - Know about the concept of forward and backward propagation
    - Understanding what is perceptron & multi-layer perceptron
- **Week 11** — Convolutional Neural Network
    - Describe the concept of convolution and its role in extracting features from image data.
    - Understand the components of a CNN, including convolutional layers, pooling layers, and fully connected layers.
    - Apply CNN with image dataset.
- **Week 12** — Dimensionality Reduction
    - Describe the "curse of dimensionality" and its implications for machine learning models.
    - Understand the PCA algorithm
    - Learn about the concept of data compression
    - Apply PCA to reduce the dimensionality of a dataset and visualize the results.
- **Week 13** — Clustering
    - Have a better idea of what Unsupervised learning
    - Understand the concept of clustering
    - Understand the concept of the K-mean algorithm
    - Learn how to calculate similarities between data points
- **Week 14** — Project presentation
    - Demonstrate critical thinking and problem-solving skills through project presentation
    - Handle questions and feedback professionally and constructively.
    - Evaluate the student performance
    - Receive any feedback to improve teaching
- **Week 15** — Review and Prepare for Final Exam
- **Week 16** — Final Exam

## Data Mining  (GICI5DM)

- **File:** `GICI5DM_Data_Mining_2024_2025.md`
- **Credits:** 1.0 · **Programme:** — · **Category:** it

### Description

Data Mining studies algorithms and computational paradigms that allow computers to find patterns and regularities in databases, perform prediction and forecasting, and generally improve student performance through interaction with data. It is currently regarded as the key element of a more general process called Knowledge Discovery that deals with extracting useful knowledge from raw data. The knowledge discovery process includes data selection, cleaning, coding, using different statistical and machine learning techniques, and visualization of the generated structures. The course will cover all these issues and will illustrate the whole process by examples. Special emphasis will be given to the Machine Learning methods as they provide the real knowledge discovery tools. Important related technologies, as data warehousing and on-line analytical processing (OLAP) will be also discussed.

### Course Learning Outcomes (6)

1. CLO1 Understanding basic concepts and techniques of Data Mining
2. CLO2 Interpret and visualize pattern explored in the dataset
3. CLO3 Improve the dataset quality through preprocessing techniques
4. CLO4 Apply the right method/algorithm on the specific set of data or data mining problem through model evaluation and assessment
5. CLO5 Implementing the data mining techniques by using tools or programming on real world problem or dataset
6. CLO6 Explore the future use and implication of data mining

## Image Processing  (GICI5IP)

- **File:** `GICI5IP_Image_Processing_2024-2025.md`
- **Credits:** 2.5 · **Programme:** — · **Category:** engineering

### Description

Image processing course provides a foundational understanding of digital image processing techniques commonly used in various engineering applications. Students will understand the fundamental principles of image processing, apply mathematical tools for image manipulation and analysis, implement image processing techniques for enhancement, restoration, and segmentation, and design and develop image processing algorithms for specific applications.

### Course Learning Outcomes (4)

1. Understanding the basic concepts of digital images, including sampling, quantization, and color models.
2. Applying linear and non-linear filtering techniques for image enhancement and noise reduction.
3. Analyze features from images for object recognition and classification.
4. Design and implement image processing algorithms using software tools (e.g., Python with OpenCV).

### Lessons (11)

- **Week 1** — Introduction to image processing
    - Fundamentals of images: representation, properties, applications.
    - Sampling and quantization
    - Color fundamentals and color models (RGB, HSI, CMYK).
- **Week 2** — Image Fundamentals
    - Sampling and quantization.
    - Spatial and frequency domain representation: Image formation model, point spread function (PSF).
- **Week 3-4** — Image Enhancement Techniques
    - Noise reduction in images: Averaging filters, median filtering.
    - Histogram processing: Equalization, stretching.
    - Spatial filtering for image enhancement: Smoothing, sharpening.
- **Week 5-6** — Image Restoration Techniques
    - Image degradation model: Blurring, noise.
    - Inverse filtering: Wiener filter.
    - Deblurring techniques: Motion blur removal
- **Week 7** — Frequency Domain Processing
    - Two-dimensional Fourier Transform (2D-DFT) and its properties.
    - Frequency domain filtering for noise reduction and image enhancement.
- **Week 8** — Morphological Image Processing
    - Basic morphological operations (erosion, dilation, opening, closing).
    - Applications of morphological operations in image analysis.
- **Week 9** — Image Segmentation
    - Thresholding techniques for image segmentation.
    - Region-based segmentation
    - Edge-based segmentation: Detection methods (Canny edge detector).
- **Week 10-11** — Feature Extraction and Object Recognition
    - Image features: Shape, texture, color.
    - Feature extraction techniques.
    - Pattern recognition and classification for object recognition.
- **Week 12** — Image Compression
    - Fundamentals of image compression
    - Run-length encoding, Huffman coding, JPEG compression.
- **Week 13** — Image Processing Applications
    - Explore real-world applications of image processing in various engineering disciplines
- **Week 14-16** — Project and Presentation
    - Implementing image processing algorithms using software tools (e.g., MATLAB, Python with OpenCV).
    - Testing and evaluating the performance of their algorithms on relevant datasets.
    - Documenting their project methodology, results, and conclusions.

### Description

This course equips you with the knowledge and skills to effectively manage information technology (IT) projects. You'll learn industry-standard methodologies, tools, and techniques to ensure successful project delivery within scope, time, and budget constraints.

### Course Learning Outcomes (6)

1. Master project management fundamentals and apply them to IT projects.
2. Define project scope and create a detailed work breakdown structure (WBS).
3. Manage project teams effectively and implement communication strategies.
4. Monitor project progress, identify and manage issues effectively.
5. Oversee project closure activities and document lessons learned.
6. Gain exposure to Agile project management methodologies for IT projects.

- **Week 8** — Project Closure and Future Considerations
