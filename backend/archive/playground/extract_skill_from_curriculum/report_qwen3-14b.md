### Description

This course focuses on studying the fundamentals of Artificial Intelligence (AI) that provide systems the ability to learn and improve from experience without being explicitly programmed automatically. this fundamental of understanding will focus on the development of computer programs that can access data and use it learn for themselves. In this class, the students will learn about some of the most effective machine learning techniques along with hands-on practices. In addition to the theoretical foundations of learning, the students will also acquire the practical know-how needed to quickly and powerfully apply these techniques to new problems.

### Course Learning Outcomes (6)

5. CLO5 Evaluate the performance of machine learning models and diagnose potential issues like overfitting or underfitting.
6. CLO6 Design and implement a machine learning pipeline to solve a real-world problem using machine learning techniques.

## Data Mining  (GICI5DM)

- **File:** `GICI5DM_Data_Mining_2024_2025.md`
- **Credits:** 1.0 · **Programme:** — · **Category:** it

### Description

Data Mining studies algorithms and computational paradigms that allow computers to find patterns and regularities in databases, perform prediction and forecasting, and generally improve student performance through interaction with data. It is currently regarded as the key element of a more general process called Knowledge Discovery that deals with extracting useful knowledge from raw data. The knowledge discovery process includes data selection, cleaning, coding, using different statistical and machine learning techniques, and visualization of the generated structures. The course will cover all these issues and will illustrate the whole process by examples. Special emphasis will be given to the Machine Learning methods as they provide the real knowledge discovery tools. Important related technologies, as data warehousing and on-line analytical processing (OLAP) will be also discussed.
