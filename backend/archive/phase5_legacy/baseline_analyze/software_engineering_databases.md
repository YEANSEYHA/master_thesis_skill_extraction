### 13. Course description / Synopsis

This course introduces students to the practical engineering of software systems
and the design of relational databases. Students learn object-oriented
programming in **Python** and **Java**, design and query **relational databases**
using **SQL**, build **web applications** with REST APIs, and apply modern software
engineering practices including **version control (Git)**, **containerization
(Docker)**, **cloud deployment**, and **Agile project management**. The course is
project-based: students design, implement, test, and deploy a working full-stack
application in teams.

### 14. Course Learning Outcomes

Here are the four CLOs of this course.

At the end of the course, students are able to:

- **CLO1 (S)** Develop software applications using **Python** and **Java** programming with object-oriented design principles, clean code practices, and unit testing.
- **CLO2 (S)** Design and implement **relational databases** and write efficient **SQL** queries for data-driven applications, including schema design, normalization, and indexing.
- **CLO3 (S)** Build and deploy **web applications** using REST APIs, **Git** version control, **Docker** containers, and **cloud** services (CI/CD pipelines).
- **CLO4 (A)** Manage a software project in a team using **Agile project management** (Scrum, Jira), effective **communication**, and collaborative problem-solving.

### 18. Course Outline / detailed lesson plan

| Week | CLOs | Topic / Lesson | Lesson Learning Outcomes |
|------|------|----------------|--------------------------|
| 1-2 | CLO1 | Object-Oriented Programming in Python | Write idiomatic Python programs using classes, modules, and object-oriented design. |
| 3-4 | CLO1 | Java Programming & Clean Code | Develop Java applications with object-oriented design, exceptions, and unit testing. |
| 5-6 | CLO2 | Relational Database Design | Design relational schemas, apply normalization, and model entities and relationships. |
| 7-8 | CLO2 | SQL & Query Optimization | Write SQL queries (joins, aggregation, subqueries) and optimize with indexing. |
| 9-10 | CLO3 | Web Development & REST APIs | Build web applications and RESTful APIs with JavaScript, HTML and backend services. |
| 11-12 | CLO3 | Version Control & DevOps | Use Git version control, Docker containers, and CI/CD pipelines for deployment. |
| 13-14 | CLO3, CLO4 | Cloud Deployment & Data Analysis | Deploy applications to the cloud (AWS) and build dashboards for data analysis. |
| 15-16 | CLO4 | Agile Project Management | Manage a software project using Scrum, Jira, and team communication; deliver a group project. |

### 19. Required resources
