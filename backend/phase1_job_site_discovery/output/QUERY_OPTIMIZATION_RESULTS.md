# Query Optimization Results — Phase 1 Discovery Pipeline

## Date: 2026-03-27
## Country Tested: Cambodia
## Model: Ollama / Qwen3:8b (free, local)

---

## Problem

The original prompt asked Qwen3:8b to generate all 10 search queries. Qwen produced:
- Repetitive English queries ("job portal cambodia", "job board cambodia", "job sites cambodia") that all returned the same SerpAPI results
- OR went fully local language, missing all English results entirely
- Result: only 4-9 confirmed job sites

## Solution

Split query generation into two parts:
1. **10 English queries are hardcoded** — diverse, covering direct search, ranking lists, city-specific, niche/industry, and classifieds
2. **5 local language queries generated by LLM** — simpler task that Qwen handles reliably
3. **Fallback** — if LLM fails, pipeline still runs with English-only queries

## Key Observations

1. **Hardcoded English queries solved consistency** — no more runs where Qwen skips English entirely
2. **List/ranking queries are high-value** — "best job websites cambodia 2025" and "top hiring platforms cambodia" pulled 10 and 8 results respectively, finding portals not in direct search
3. **3 English queries returned 0 results** — "job board cambodia", "cambodia recruitment website", "cambodia classifieds jobs" could be replaced with better alternatives
4. **Local language queries still valuable** — found sites not in English results (government sites, local portals)
5. **Verification accuracy is strong** — Qwen correctly rejected 18/18 non-job sites

## Key Observations (Updated)

1. **Hardcoded English queries solved consistency** — no more runs where Qwen skips English entirely
2. **List/ranking queries are high-value** — "best job websites {country} 2025" and "top hiring platforms {country}" consistently pull 8-10 results
3. **3 English queries consistently return 0 results** — "job board {country}", "{country} recruitment website", "{country} classifieds jobs" could be replaced
4. **Local language queries still valuable** — found sites not in English results
5. **Verification accuracy is strong** — Qwen correctly rejects non-job sites >95% of the time

7. **SerpAPI free tier is a bottleneck** — 100/month limits testing to ~6-7 countries
